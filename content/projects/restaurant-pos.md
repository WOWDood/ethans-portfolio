## Project

I built POS System XE for my Software Engineering course. The browser-based demo lets restaurant staff open table orders, edit order items, record payments, and generate receipts. I designed the workflow with commercial use in mind.

## My contribution

I developed the application in Laravel, built the interactive POS interface with Livewire 4, and used Microsoft SQL Server for data storage.
